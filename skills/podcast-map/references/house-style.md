# 个人视觉合同与配色

这是共同语言，不是整页模板。复制 [visual-contract.yaml](../templates/visual-contract.yaml) 到知识包；颜色只在 `palette.json` 定义一次。

## 系列不变量

- 所有画布和封面阅读面板始终纯白。局部语义浅填充可以存在，不得替代整页白底。
- 正文、主标题与结构分隔线以深色或中性色为主；短判断标题优先一行，最多两行。封面保留准确原标题。
- 保留 Excalidraw 手绘线感及可编辑源；封面固定骨架见 [cover-design.md](cover-design.md)。
- 页眉有系列标识与右上进度；页脚一条分隔线、来源与页码。跨区段来源可列不连续时间范围，但不重复范围，不排成多条竞争信息。
- 正文不逐段标时间，不展示“编辑解读”等生产注释；有叙事意义的时间锚点可保留。
- 插图只解释人、物、动作、尺度或关系，不以装饰填空。

## 每套一致，不同来源可以变化

深色阅读骨架加至多两种强调色，职责明确，但色相不是永久红绿映射：

- `primary`：本套主强调角色，例如主机制、有效路径或关键参与方；
- `contrast`：需区分的风险、替代路径或另一类参与方；不必每页都用；
- `ink / muted / line`：正文、辅助来源、中性线条；
- `primarySoft / contrastSoft`：局部浅填充，不作正文。

有色文字承担语义区分、关键判断或稳定导航，能说明优先辨认的理由。同组同义同色，不逐句换色；不靠彩色面积配额证明克制，也不删光强调色造成黑压压的文章页。含义还需文字、位置或形状表达，不能只靠分色。

新来源定色时，查看可取得的最近三套**不同来源**的成品或配色记录。同集 v1、v2、v3 只算一套，修订不自动换色。结合题材、对比度与邻近作品，通常改变至少一个强调色相家族；只改几个 hex 数字不算新鲜。允许有理由的连续配色，不机械轮换；没有历史就记录限制，不编造。

封面自绘文字仅用 `ink` 和选定的一个强调角色，与正文同源。官方节目图片保持原色，不计入自绘强调色上限。

## 唯一配色文件

新包创建 `palette.json`；尖括号按实际选择填写，不提供可无意识继承的红绿默认值：

```json
{
  "source_id": "<稳定来源地址或标识>",
  "roles": {
    "paper": "#FFFFFF",
    "ink": "<六位色值>",
    "muted": "<六位色值>",
    "line": "<六位色值>",
    "primary": "<六位色值>",
    "contrast": "<六位色值>",
    "primarySoft": "<六位色值>",
    "contrastSoft": "<六位色值>"
  },
  "meanings": {
    "primary": "<本套具体职责>",
    "contrast": "<本套具体职责>"
  },
  "cover_accent": "primary",
  "selection": {
    "recent_sources": [],
    "reason": "<去重后的近期来源、选色理由；无历史则说明限制>"
  }
}
```

有历史时，每项包含 `source_id`、`primary`、`contrast`。配色文件不是成品通过证明。

正文与封面生成器必须读取同一 JSON，用 `scripts/palette.mjs` 的 `createPalette` 校验并取得角色值；不各自复制色值或静默回退到旧常量。旧稿定向返修不强制换色或迁移；经授权换色时才统一迁移受影响渲染链。

## 模块秩序

先分区，建立共同左边线、基线、列宽或中心轴。不要围图随手塞字；线条帮助分组，不切碎整体。先保证手机正文可读；留白服务停顿与关联，不遮掩内容不足。

已批准结构、字号和颜色按页面选择记录冻结。新鲜感来自内容关系和跨来源的受控变化，不来自每轮重设计系列语言。
