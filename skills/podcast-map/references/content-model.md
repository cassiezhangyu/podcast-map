# 理解与解读：先形成可读母稿

先帮助读者理解节目，再为传播选择表达。内容模型是证据底账，knowledge.md 是可独立阅读的解读母稿；二者在页面规划前形成，不从图片反向拼接。

## 来源与覆盖

按 [transcription.md](transcription.md) 核验材料。记录准确节目与单集标题、链接、发布日期、时长、音频与转写覆盖、输入范围与缺失。为关键术语给出原始形式、通俗释义与证据位置；不能为版式改掉专有名词。

按实质章节建立紧凑覆盖表，分别记录：
- 理解层：充分解释、归并重复、暂不确定或省略及原因；
- 发布层：总览交代、深读展开、仅保留在母稿及原因。

不要因为难画、不能支持宣传切口就删去重要分支。来源含有不确定或矛盾不等于输入缺失；忠实保留其不确定性也是完整理解。

### 可追溯证据单元

为会改变整体理解的来源主张建立稳定短编号，例如 `U1`、`U2`。每个单元至少记录：说话人、精确锚点、简要主张、它与其他单元的关系、理解层处理和发布去向。锚点使用时间范围或稳定的转写片段编号；不要只写“前半段”“某处”。

综合判断另用 `S1` 等编号，并显式列出它依赖的来源单元，例如 `S1 = U2 + U5`。说明补出的推理步骤和关系类型；若只是时间先后、类比或价值并置，不写成因果。外部核验用独立来源链接和状态，不伪装成原材料单元。

不是每句话都要编号。优先覆盖中心判断、关键关系、分歧、反例、数字和会进入总览的内容；编号服务回查，不把公开图片变成脚注墙。

## 组织中心，不强造单一结论

材料可以围绕一个主论点，也可以是中心问题下的多个发现、分歧立场或探索分支。选择实际结构，不把访谈硬改成步步必然的论证。

沿用 governing_thesis / reasoning_movements 字段时：前者可填写中心问题，后者可容纳必要分支，注明彼此关系；不必另造复杂本体或知识图谱数据库。

每个主要单元说清：在问什么、来源怎么回答、为什么、证据是什么、哪里有限制。删除测试应问“是否损失来源的重要理解”，而不是仅问“是否支持选定主论点”。相关但无法统一的观点可以并置，不代替说话人调和矛盾。

## 二次咀嚼的工作

根据难点进行必要加工，不要求每条知识都套固定解释层数：
- 解释术语及易混概念；使用来源例子帮助理解。
- 把散落的解释合到同一问题下，补出省略的推理步骤。
- 区分原因、条件、先后顺序、例证、反例、对照与价值分歧。
- 将关键关系写成完整句子，例如“A 在条件 C 下影响 B，证据是……”，而不是只列两个名词和一根箭头。
- 说明成立前提、代价及不能推出的结论。推理跳步应标明是综合推断，不能伪装成原话。
- 来源不足时保留问题，不通过陌生案例、空泛行动建议或抽象术语伪造深度。

## 判断与证据边界

内部沿用 source_claim、editorial_synthesis、extension，分别代表来源主张、跨段综合和谨慎延伸。多位说话人的主张保留归属；谁说的、是否同意，不能靠语气猜测。

忠实记录来源不等于证明其事实正确。重要数字、专名、事实若存在疑点，先回原文或原声核验；需要外部事实核验时使用可靠来源并另记出处及核验状态，不将外部结论混作原材料。未核验就说明限制，不打虚构置信分。高风险结论不因为来源说过就变为通用建议。

公开文案自然表达，例如“把这几段放在一起，可以理解为……”或“这里仍不能确定……”，无需每段贴“编辑解读”标签，但必须保留必要的归属、条件与不确定性。

## 可独立阅读的 knowledge.md

开头先写一个紧凑的“快速理解”入口，使读者无需先浏览图片或读完整篇就能回答：材料的中心问题是什么，来源给出了哪些主要回答，它们如何关联，以及最重要的限制或分歧是什么。用自然段或最适合材料的结构，不强制固定题数、五点清单或行动结论。

随后按材料自然组织完整解读，不保留空标题：
- 这份内容在讨论什么，以及重要发现；
- 必要概念、主线与不可忽略的分支；
- 为什么这样理解：机制、例子、对照或处境；
- 分歧、易误解之处、边界与未解问题；
- 对读者有价值的新判断，以及可以回看的来源位置。

不是缩写转写稿，也不是页码说明书；读者即使不看图片，也能理解。生活叙事可以以更准确的看法或仍值得追问的问题收束，不强制行动清单。

读者未说明背景时，暂按“愿意深入阅读、但不预设掌握本领域术语”的受众解释。在 content-model.md 简记此假设，有明确受众再调整；不要每次停下来问相同问题。

## 理解验收与交给页面编辑

按 [quality-gates.md](quality-gates.md) 的理解预检，用少量代表性问题检查复述、关系、辨析、边界及追溯。记录实际回答、证据和缺口，不只写 PASS，也不声称用户已经理解。生产者自问自答不叫独立验证；用户选择在真实使用中持续优化时，记录该边界，不额外建立评测集。

母稿通过本次适用的内容预检后再规划图片。以后发现内容错误，先修母稿及证据底账，再同步受影响的图片和文案；只改字号或位置时不重写母稿。
