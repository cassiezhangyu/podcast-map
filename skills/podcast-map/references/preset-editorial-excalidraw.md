# 个人编辑式视觉预设

`editorial-excalidraw-v1` 是本 skill 默认的个人视觉预设，不是长内容理解方法本身。用户只要理解稿时不加载它；用户明确选择其他视觉方向时，保留来源、内容模型、证据关系和页面贡献，只替换视觉合同及实现。

## 预设识别

- 1200×1600、3:4；总览和深读正文纯白画布；
- 深色阅读骨架、同套固定的语义强调色、Excalidraw 手绘线感；
- 总览是高密度旗舰页，深读按真实阅读任务变化，不复用整页模板；
- 页眉系列标识与进度、单线页脚、来源和页码；
- 封面使用 [cover-design.md](cover-design.md) 的固定叠层与编辑式母版；
- 信息性图形服务关系、比较、处境或尺度，不用装饰插图填空。

具体字号、配色和例外仍记录在知识包的 `visual-contract.yaml` 与 `palette.json`。预设定义共同语言，不决定标题内容、页面数量、每页模块或知识关系。

## 替换视觉预设时

新预设至少声明画布、字体可读性、颜色职责、导航、封面、可编辑源和手机验收方式。不得为了适配新风格回写或删改 knowledge.md 的重要分支，也不能把未经用户确认的视觉探索升级为系列偏好。
