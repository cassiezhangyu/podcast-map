# 已批准的编辑式社交封面

除非用户明确要求其他封面风格，知识包默认采用本方向。它保留 E163 封面校准第一版已经认可的优点，但不复制来源特有的文字。正文按内容探索结构，封面保持系列母版；两者的创新尺度不同。固定的不只是外框，还包括大字主导的标题层级与阅读节奏。

## 构建顺序

1. 以最终 3:4 尺寸完成并导出独立高密度信息图。
2. 将该准确导出图用作满画布背景。不得裁成小窗口，也不得用通用纹理替换。
3. 总览底图先降低饱和度、轻微柔化，再叠灰色半透明蒙版，让真实知识结构退到背景；不是把总览降到极低不透明度而漂白。底层画布可以纯白，但封面合成结果不要求纯白；正文白底规则不取消封面的蒙版。
4. 中部阅读面板使用微透暖白，保持已批准的矩形结构与固定几何，无装饰；与外围灰色背景形成层次，隐约透出内容，而不是不透明白块。
5. 面板内先放一条短强调线，再以最大字号呈现准确原标题。选择一种高对比结构文字色，外加至多一种克制强调色。若标题适合拆分，开头短语与转折或解决部分可分别使用这两个角色；炭黑与珊瑚色只是已批准参考中的示例，不是永久默认值。
6. 用细中性分隔线隔开核心主题副标题。副标题应以一到两行精炼文字表达材料的核心问题或张力。
7. 对于播客，把经核验的节目封面图作为紧凑来源身份锚点，放入编辑式信息面板内规范的右上角图框。优先使用来源平台发布的准确图片；只有平台明确把单集图片作为该集身份时，才使用权威单集封面。默认只放一张，保持宽高比，不得改色、重绘或用通用播客图标替换。该图框属于播客系列识别，不因标题较短或下方来源区稀疏而在不同知识包间移动。若无法取得官方图片，记录限制并保留相同封面骨架，有意留空图片位置，或采用平衡的纯文字处理；不得虚构图片。
8. 加入克制的来源识别文字，通常在信息面板内占一到两短行。图片和元数据应通过对齐、间距与层级读成同一个来源系统，但不必彼此相邻或共用底部一行。使用足以识别节目、又不与标题竞争的信息：平台、节目或联合节目、集数或准确单集标题、时长。有节目语境时，避免只显示孤立集数。

## 1200 × 1600 播客封面规范几何

- 画布：1200 × 1600，3:4 竖版；
- 背景处理：最终总览饱和度0.30、亮度0.90、模糊2.4px；覆盖 `RGB(104,110,116)`、不透明度0.56的灰色蒙版。参数来自已通过的v20/v5.3渲染器；
- 编辑式信息面板：`x=88, y=260, width=1024, height=1000, corner radius=5`，`#fffaf0`，不透明度0.94；节目图片框同色、不透明；
- 左侧内容基线：`x=158`；右侧内容边界：`x=1040`；
- 强调线：`x=158, y=350, width=120, height=8`；
- 标题区：第一条基线 `y=500`，主字号 116 px 粗体；三行步进 136 px，四行适配步进 114 px；局部长行字号适配见下节；
- 播客图片框：`x=906, y=330, width=152, height=152, corner radius=22`；图片本身：`x=916, y=340, width=132, height=132, corner radius=16`；
- 分隔线：从 `(158, 905)` 到 `(1040, 905)`，3 px；
- 核心主题副标题：第一条基线 `y=985`，通常为 42 px，行步进 60 px；
- 来源识别区：第一条基线 `y=1160`，通常为 27 px，行步进 43 px；
- 可见安全边距：主文字系统距信息面板内侧至少 70 px。

这些坐标是系列不变量，不是宽松起点。若准确标题异常长，移动结构锚点前，先在预留标题区内调整换行、字距和标题字号。除非用户明确要求不同封面方向，否则信息面板、图片框、分隔线、副标题区和来源基线保持不变。

## 固定母版与受控适配

- **固定**：上述几何与叠层参数、水平左对齐、粗体标题主导、圆角节目图片、中性细线及来源层级。封面蒙版和面板是固定材质角色，不随正文强调色更换。不得为了容纳文字每次重新拼一份 SVG。
- **可变**：准确标题及完整短语的断行、副标题、实际来源、与正文同源的一种强调色。标题强调连贯的语义部分，不交替染色。
- **长标题适配**：优先三行；原标题容纳困难时用四行，记录语义断行理由。不拆完整词组，不让逗号或片段单独成行。默认 116px，只对实际过长的行局部降至 88–116px，至少一行保持 108px 以上。这是防止整体缩字的技术护栏，不是视觉通过证明，也不是要求所有行等大。仍放不下或系列感明显变弱时，报告并请求例外，不擅自删改原标题、移动锚点或继续缩字。
- 原尺寸与 420px 图核验真实字体、字形宽度和行间净空；字符数不能代替真实渲染。不同机器应使用实际可用的同类中文黑体并复查，不以字体回退后的无报错认定一致。

### 唯一生成入口

新包使用 `scripts/cover-system.mjs`，几何只维护在该组件中；包内 `cover-layout.json` 只保存文案与允许变化的参数。不可复制上一期临时封面脚本作为新母版。旧批准稿不追溯迁移；用户要求返修封面时才接入，并保留旧稿。

组件先用 Sharp 按批准参数处理原始总览，再生成内嵌背景的自包含 SVG；验收从原始总览重新计算，不接受手动指定一张无法追溯处理过程的背景图。项目可正常解析 `sharp` 时直接使用；工作区提供独立依赖路径时，设置 `KNOWLEDGE_SHARP_MODULE` 为实际模块路径，不在 skill 写死某台机器的绝对路径。调用者已有 Sharp 实例时可传给 `await expectedCover(root, sharp)`。

`cover-layout.json` 包含：`system: "editorial-fixed-v1"`、`source_type: "podcast"`、经核验的 `original_title`、`title_lines`（每行 `text`、`font_size`、`role: "ink" 或 "accent"`）、一到两行的 `subtitle` 和 `source_lines`。四行另填 `adaptation_reason`。填入包内相对路径 `podcast_image`；无法取得官方图片时留空并填 `missing_image_reason`，不虚构图片。

```sh
node <skill目录>/scripts/cover-system.mjs <知识包目录> --write-svg
# 用现有渲染器将 editable/cover.svg 导出为 cover.png 和手机预览。
node <skill目录>/scripts/cover-system.mjs <知识包目录>
node <skill目录>/scripts/check_release_artifacts.mjs <知识包目录>
```

复制新版视觉合同时保留 `cover_system`。检查器根据当前总览、官方图片、文案和配色重新构建预期 SVG，再与实际源文件比较；不能只靠声明坐标正确通过。检查不验证 PNG 栅格同步与排版审美，仍需用最终 SVG 渲染并目检。旧合同只提示未覆盖，不能称其封面通过；非默认风格须有用户授权，不静默删除检查标识绕过约束。

系列封面一旦被用户批准，正文页的定向返修必须冻结封面。只有用户明确要求修改封面，或最终总览背景本身发生变化，才允许重新渲染；重新渲染也必须以批准封面的结构快照为基线，逐项比较信息面板、标题区、右上图片框、分隔线、副标题区和来源基线。颜色或文案变化不构成移动骨架的理由。

准确原标题内部原本没有的运算符、加减号、等号、箭头、档案标签或英文栏目字样，不得为了“更有设计感”插入标题区。它们会制造第二套叙事和新的视觉焦点，也会破坏系列一致性。只有符号属于经核验的原标题时才可保留，并仍需服从标题区的语义换行。

## 标题配色接入

配色只按 [house-style.md](house-style.md) 决策。封面读取与正文相同的 `palette.json`，自绘文字用 `ink` 与 `cover_accent` 指向的一个强调角色，包括标题、副标题和来源。不得保留独立封面默认色值。官方节目图片不改色。

跨来源变化不授权修改信息面板、标题区、右上图片框、分隔线、副标题区或来源基线。同一包修订保留已批准颜色，除非用户授权换色。

## 固定排除项

- 不使用装饰图标、涂鸦、假贴纸、装饰边框或无关插画；
- 不使用竖排文字或横竖混排标题系统；
- 不使用多个高饱和彩色区块、彩虹标题、档案编号、分类标签、时长徽章或设计演示元数据；
- 不使用游离的平台徽章或推广标签；经核验的播客封面图只有在与来源系统保持视觉联系且从属于标题时，才可作为信息面板内的紧凑身份锚点；
- 不添加游离的 `PODCAST` 字样、加号、减号、等号、箭头或其他伪公式构图；除非它们属于准确原标题；
- 不使用黑色主导封面、玻璃拟态、电影式光晕或无关背景图；
- 封面不显示制作语言、提示词片段或要求；
- 不以改写的耸动标题替代准确来源标题。

## 封面质量检查

- 缩略图尺寸下，准确标题先于背景内容被读到。
- 总览在底层仍可被感知，使封面明确来自该知识包。
- 信息面板与标题具有安全边距；文字不靠近面板边缘或画布边缘。
- 封面只有一个焦点层级，没有多个竞争区块。
- 标题色对可读、属于当前知识包，且不是自动复用最近封面。
- 当前 `palette.json` 记录去重后的近期来源、选定角色与选色理由；封面实际文字色与之相符。
- 所有封面文字——包括来源元数据和副标题——不超过声明的两个颜色角色。
- 来源元数据能识别实际材料，而不是只显示孤立集数或期号。
- 可获得时，播客封面使用右上角规范图框放置经核验的节目图片。图片与来源文字仍读成一个溯源系统，在缩略图尺寸下可识别，不变形，并从属于准确单集标题。
- 官方播客图片不可获得时，审计记录限制，封面使用纯文字来源区，不出现通用或虚构替代图。
- 副标题提供方向，不重复标题。
- 封面不计作独立信息图或深读页。
- 与最近批准的同系列封面逐项比较后，信息面板、右上图片框、分隔线、副标题区和来源基线没有漂移；定向正文返修中封面文件保持冻结。
- 最终封面与批准稿同尺寸并排查看：底图是否保留朦胧质感、灰色蒙版和微透面板是否形成层次；标题是否仍为第一视觉、是否明显缩小或碎片化、图框和线条是否一致。不能只检查坐标或自报参数；在包内已有 `quality-audit.md` 记录参考稿、实际差异及未通过点。用户的白底要求按作用范围执行，正文白底与封面叠层分别核验。
